## 比较与审计边界

- B3 使用原 A2 **初始**记录的有界、脱敏呈现，独立请求、无工具。A2 的 FixFirst 第一步允许来自 Find it 后状态；比较时须说明工具条件差异，不能写成完全相同的信息与操作条件。
- 输入沿 A 的 v2 交接和固定 builder 核验，原 session 文件仍由 A 保存，B 不能独立重算未收到的原文件摘要。
- 五故障类根因指标、健康项目表现、人工第一步质量和技术可用性分别报告。可解析不代表建议正确，文字建议也不代表已经执行并修好。
- `timeout=1200` 是 socket I/O 超时，服务有 keepalive，没有硬性 20 分钟墙钟截止。逐请求耗时和 token 用量保留在本地，评分结束后再披露对应模型明细与计数差异。
- `RECEIPT.json` 只公开匿名交接所需的固定提交、摘要、参数和总量。原响应、模型身份映射、完整输入、配置和日志暂由 B 保管。公开校验和可核对本包字节，不能替代对未公开原始记录的独立重算，也不是数字签名。
- 评分表未见模型自报身份，但匿名化不能保证评分者无法从文风或失败模式猜测；如有破盲迹象，请记录，保留原回答。
