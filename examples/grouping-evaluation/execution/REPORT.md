# Message grouping experiment

30 controlled cases. Pairwise precision/recall of grouping error messages that share a cause (threshold 0.82, set before evaluation).

| Method | Precision | Recall | TP | FP | FN |
|---|---|---|---|---|---|
| exact | 1.000 | 1.000 | 5 | 0 | 0 |
| tfidf | 1.000 | 1.000 | 5 | 0 | 0 |

Controlled execution faults in a shopping-cart template; the five variants are structurally similar and not naturally occurring failures.
