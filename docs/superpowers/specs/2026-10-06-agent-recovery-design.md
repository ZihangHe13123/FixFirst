## 运行器

- H3 的空回复与有文字但无工具的回复共用最多三次提醒。提醒占轮数，预算不变；默认零提醒、拒绝、非 stop 结束、畸形回复、截断调用的行为保持原规则。先封存完整回复，再判定或执行。
- 两组共用系统提示写明判分在项目目录使用 python -m pytest。新批次两个模型的两组都重跑，新输入不与旧输入混合。
