# FixFirst 首版实现约定

依据已讨论的 PRD 和技术文档实施，用户于 2026-09-08 授权直接开发。

产品为本地 Python 包、命令行和静态 HTML 报告。首版覆盖 pip 检查及安装日志导入、pytest 测试收集、Ruff 检查。检查由用户主动触发，不自动安装项目依赖或修改源码。

实现顺序：共享数据与存储 → 有界检查执行与解析 → 归并和分类 → 前向推理及行动排序 → 范围感知状态更新 → 报告和命令行 → 真实案例与实验 → 完整验收及使用说明。

验收重点：相似不是因果；不同组件不可仅凭异常类别合并；部分重跑或运行失败不能关闭未验证问题；清单依据可回到日志；模型预测不得替代已观察事实。规则/TF-IDF 基线可离线使用，Sentence-BERT 为可选本地模型，缺失时明确报错，不假装运行。

训练及实验用自建可撤销故障案例，不将其当真实用户数据；训练、验证、测试按项目分离。评价结果保留失败和小样本局限。三类课程方法是否有效由实际实验说明。

本轮不调用外部付费模型，不上线服务，不改原课程文档。所有运行与产出状态写入最终交付说明。
